О студии

BecauseDev IT Studio — независимая студия разработки игр в жанре мобильного хоррора. Мы создаём собственные проекты, вкладывая в каждый из них уникальный сценарий, механику и атмосферу.

Кто мы

Мы — команда разработчиков, увлечённых хоррор-жанром. Наши игры строятся на продуманных механиках, психологическом напряжении и внимании к деталям. Мы не копируем чужое — мы создаём своё.

Наш подход

Каждый проект начинается с идеи и сценария. Мы продумываем лор, персонажей, механику взаимодействия и уровень страха ещё до первой строки кода. Только потом приступаем к разработке.

Чем мы занимаемся

  • Разработка оригинальных мобильных хоррор-игр
  • Создание собственных 3D-локаций, персонажей и анимаций
  • Написание авторских сюжетов и геймдизайна
  • Публикация APK-файлов и релизов через официальные платформы
  • Развитие сообщества игроков и обмен опытом с другими разработчиками

Принципы

  • Качество важнее скорости. Лучше позже, но лучше.
  • Оригинальность. Свои идеи, свой стиль, свой сценарий.
  • Открытость. Общаемся с игроками, публикуем код, делимся опытом.
  • Уважение к жанру. Хоррор — это искусство, а не набор скримеров.

Технологии

  • Godot Engine 4.7 — основной игровой движок
  • GDScript — язык программирования игровой логики
  • Blender — для создания и редактирования 3D-моделей
  • GitHub Pages — для сайта и публикации релизов

О игре:

Психологический хоррор в заброшенном викторианском поместье кукольницы. Главный антагонист — Мадам Хелена, слепая старуха с феноменальным слухом и тростью с клинком. Игрок должен сбежать из поместья за пять ночей, используя звук, прятки и подручные предметы.

  • Потайные ходы внутри стен
  • Второстепенные угрозы — "Сломанный мальчик" Тимоти, паукообразная кукла
  • Две концовки: обычный побег и побег на катафалке

Open Source

Virtual Joystick

Язык: GDScript (Godot 4.7)

Лицензия: MIT — используйте свободно, будем рады упоминанию BecauseDev IT Studio.

Описание

Универсальный виртуальный джойстик для мобильных игр на Godot 4. Поддерживает тач-управление, плавное перемещение стика и отдаёт вектор направления direction (Vector2) для движения игрока.

Код (joystick.gd)

extends Control

@export var max_radius = 100.0
@export var stick_radius = 40.0

var center = Vector2.ZERO
var stick_pos = Vector2.ZERO
var active_touch = -1
var direction = Vector2.ZERO

func _ready():
	center = size / 2
	stick_pos = center

func _draw():
	draw_circle(center, max_radius, Color(1, 1, 1, 0.25))
	draw_arc(center, max_radius, 0, TAU, 48, Color(1, 1, 1, 0.7), 3.0)
	draw_circle(stick_pos, stick_radius, Color(1, 1, 1, 0.6))
	draw_arc(stick_pos, stick_radius, 0, TAU, 48, Color(1, 1, 1, 0.9), 3.0)

func _gui_input(event):
	if event is InputEventScreenTouch:
		if event.pressed and active_touch == -1:
			active_touch = event.index
			_update_stick(event.position)
		elif not event.pressed and event.index == active_touch:
			active_touch = -1
			stick_pos = center
			direction = Vector2.ZERO
			queue_redraw()
	elif event is InputEventScreenDrag:
		if event.index == active_touch:
			_update_stick(event.position)

func _update_stick(pos):
	var offset = pos - center
	if offset.length() > max_radius:
		offset = offset.normalized() * max_radius
	stick_pos = center + offset
	direction = offset / max_radius
	queue_redraw()

Информация о нас

BecauseDev IT Studio — небольшая независимая команда разработчиков, создающая фанатские игры по мотивам вселенной Ice Scream и других хоррор-проектов.

Кто мы такие

Мы — фанаты жанра мобильных хорроров и, в частности, игр студии Keplerians. Нас вдохновили такие проекты, как Ice Scream, Evil Nun, Granny и Mr. Meat. Мы решили не просто играть, а создавать своё — продолжения, ремейки и собственные идеи в этом жанре.

Чем мы занимаемся

  • Разработка фанатских игр в жанре mobile first-person horror
  • Создание собственных 3D-локаций, персонажей и анимаций
  • Написание сюжетов и сценариев по мотивам известных вселенных
  • Публикация APK-файлов наших игр в открытом доступе
  • Развитие сообщества и обмен опытом с другими разработчиками

Наш подход

Мы верим, что качество важнее скорости. Каждый проект мы делаем с душой, продумывая каждую деталь: от механики управления до атмосферы и звука. Мы не гонимся за хайпом — мы делаем то, что нам самим было бы интересно играть.

Open Source

Virtual Joystick

Язык: GDScript (Godot 4.7)

Лицензия: MIT — используйте свободно, будем рады упоминанию BecauseDev IT Studio.

Описание

Универсальный виртуальный джойстик для мобильных игр на Godot 4. Поддерживает тач-управление, плавное перемещение стика и отдаёт вектор направления direction (Vector2) для движения игрока.

Установка

  • Создайте узел Control в вашей сцене
  • Прикрепите скрипт joystick.gd
  • Разместите в левом нижнем углу (размер ~280x280)
  • Читайте joystick.direction в скрипте игрока

Код (joystick.gd)

extends Control

@export var max_radius = 100.0
@export var stick_radius = 40.0

var center = Vector2.ZERO
var stick_pos = Vector2.ZERO
var active_touch = -1
var direction = Vector2.ZERO

func _ready():
	center = size / 2
	stick_pos = center

func _draw():
	draw_circle(center, max_radius, Color(1, 1, 1, 0.25))
	draw_arc(center, max_radius, 0, TAU, 48, Color(1, 1, 1, 0.7), 3.0)
	draw_circle(stick_pos, stick_radius, Color(1, 1, 1, 0.6))
	draw_arc(stick_pos, stick_radius, 0, TAU, 48, Color(1, 1, 1, 0.9), 3.0)

func _gui_input(event):
	if event is InputEventScreenTouch:
		if event.pressed and active_touch == -1:
			active_touch = event.index
			_update_stick(event.position)
		elif not event.pressed and event.index == active_touch:
			active_touch = -1
			stick_pos = center
			direction = Vector2.ZERO
			queue_redraw()
	elif event is InputEventScreenDrag:
		if event.index == active_touch:
			_update_stick(event.position)

func _update_stick(pos):
	var offset = pos - center
	if offset.length() > max_radius:
		offset = offset.normalized() * max_radius
	stick_pos = center + offset
	direction = offset / max_radius
	queue_redraw()
